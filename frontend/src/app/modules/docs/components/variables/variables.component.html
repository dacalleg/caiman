Modifica variabili/parametri di lavoro

Quando si effettua la connessione con il dispositivo verranno mostrate oltre alle voci di menù classiche(INFORMAZIONI DISPOSITIVO, TICKETS, AVANZATE, LOG INTERVENTI) una serie di altre voci di menù che corrispondono a dei gruppi di variabili/parametri. La numerosità di questi gruppi dipende essenzialmente dal dispositivo a cui ci si è connesso. Cliccando su un gruppo verrà visualizzata una schermata che contiene le variabili/parametri di quel dato gruppo. Per ciascuna variabile verrà visualizzato un riquadro contenente:

  • Il nome della variabile/parametro
  • Il valore letto in tempo reale
  • Un pulsante di modifica(a forma di penna)

Per modificare un valore è sufficiente cliccare il pulsante di modifica. Comparirà un'area di testo o una casella di selezione nel caso di valori predefiniti. Dopo 1 secondo circa dalla modifica del campo il valore verrà scritto nella scheda.
